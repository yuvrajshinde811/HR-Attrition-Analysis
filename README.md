# HR Attrition Analysis

## Project Overview

This project analyzes employee attrition patterns using the IBM HR Analytics dataset.

The objective is to identify the key factors influencing employee turnover and provide actionable business insights.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook
* Power BI

## Dataset

* IBM HR Analytics Employee Attrition Dataset
* Total Employees: 1470
* Features: 35

## Data Cleaning

* Removed duplicate records
* Removed unnecessary columns:

  * EmployeeCount
  * StandardHours
  * Over18
* Converted Attrition into binary format

## Feature Engineering

Created:

* TenureBucket
* SalaryBand
* HighRiskFlag

## Key Findings

* Overall Attrition Rate: 16.1%
* Employees Who Left: 237
* Sales Department has the highest attrition (20.6%)
* Overtime employees show nearly 3x higher attrition
* Low salary employees have the highest attrition rate
* New joiners (0–2 years) are at highest risk
* 56 employees identified as High Risk
